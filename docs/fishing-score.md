# Fishing Score — สูตรและน้ำหนัก

เอกสารนี้คือ "ที่มา" ของทุกตัวเลขที่ `/api/score.php` คืนออกไป
สัญญาหลักเขียนไว้ว่าห้ามแสดงตัวเลขที่อธิบายที่มาไม่ได้ — เอกสารนี้คือคำอธิบายนั้น
**แก้สูตรหรือน้ำหนักในโค้ดโดยไม่แก้ที่นี่ = ผิดกติกา** และชุดทดสอบจะจับได้

## Fishing Score คืออะไร และไม่ใช่อะไร

**เป็น** เครื่องมือช่วยตัดสินใจว่า "วันนี้น่าออกไหม และเหมาะกับงานแบบไหน"
สร้างจากสภาพจริง (ลม คลื่น น้ำ ดวงจันทร์ แสง) ผ่านน้ำหนักที่ **ทีมเราเลือกเอง**

**ไม่ใช่** คำพยากรณ์ว่าจะได้ปลา และ **ไม่ได้** มาจากการวิเคราะห์สถิติการจับปลาจริง
งานวิจัย [Quigley, Gonzalez & Kauwe (2023)](https://www.researchgate.net/publication/370948823_Popular_solunar_tables_fail_to_predict_fishing_success_in_North_American_recreational_freshwater_trout_fisheries)
ทดสอบการออกตกปลาจริง 361 ครั้ง พบว่าค่า solunar ข้างขึ้นข้างแรม และความสว่างของดวงจันทร์
**ไม่มีความสัมพันธ์อย่างมีนัยสำคัญ** กับอัตราการจับ

เรารู้เรื่องนี้และยังใส่ solunar ไว้ในสูตร เพราะคะแนนนี้มีไว้ช่วยวางแผนและสร้างความตื่นเต้น
ไม่ได้อ้างว่าเป็นวิทยาศาสตร์ **ทุกคำตอบจึงต้องแนบ `notice` ที่พูดเรื่องนี้ตรง ๆ ห้ามตัดออก**

## ความปลอดภัยไม่ใช่ปัจจัยหนึ่งในคะแนน

`safety` แยกออกมาเป็นก้อนของตัวเอง และ **ไม่ถูกกลบด้วยคะแนนสูง**
วันที่ลมแรงจนอันตราย คะแนนงานที่ต้องใช้เรือจะตกเองตามน้ำหนักลม/คลื่น
แต่ผู้ใช้ต้องเห็นคำเตือนแยกอีกชั้นด้วย เพราะคะแนน 70 กับ "ลมแรงเกินไปสำหรับเรือเล็ก"
เป็นคนละคำถาม และคำถามหลังสำคัญกว่า

เกณฑ์อ้างอิง [small craft advisory](https://en.wikipedia.org/wiki/Small_craft_advisory) และมาตรา Beaufort:

| ระดับ | เงื่อนไข | ความหมาย |
|---|---|---|
| `good` | ลม < 20 กม./ชม. และคลื่น < 1.0 ม. | ออกได้ |
| `caution` | ลม 20-40 กม./ชม. หรือคลื่น 1.0-2.0 ม. | ระวัง เรือเล็กควรคิดให้ดี |
| `dangerous` | ลม ≥ 40 กม./ชม. (~Beaufort 6) หรือคลื่น ≥ 2.0 ม. | ไม่ควรออกด้วยเรือเล็ก |

## ปัจจัยร่วม (factors)

ทุกปัจจัยถูกทำให้เป็นค่า 0.0-1.0 ก่อนเข้าสูตร แต่ละงานเอาไปคูณน้ำหนักของตัวเอง

### 1. `water_movement` — แรงการไหลของน้ำ

**ปัจจัยที่มีหลักฐานหนุนดีที่สุดในบรรดาทั้งหมด** หลายแหล่งตรงกันว่า
[ความเร็วกระแสน้ำสำคัญกว่าระดับน้ำ](https://bassanglermag.com/tides-and-bass-fishing-master-tidal-patterns-in-2026/)
ปลานักล่าตั้งซุ่มรอเหยื่อที่น้ำพัดมา ช่วงน้ำนิ่ง (slack) มักแย่ที่สุด

คำนวณจากอนุพันธ์ของ `series` ใน `/api/tides.php`: `|Δh/Δt|` ของชั่วโมงที่สนใจ
เทียบกับอัตราการเปลี่ยนสูงสุดของวันนั้น → 0.0 (น้ำนิ่ง) ถึง 1.0 (น้ำเดินแรงสุดของวัน)

### 2. `tidal_range` — น้ำเกิดหรือน้ำตาย

`max(series) - min(series)` ของวันนั้น เทียบกับช่วง 0.2-1.2 ม. ซึ่งเป็นพิสัยที่พบจริงในอ่าวไทย
น้ำเกิด (พิสัยกว้าง) = น้ำเดินแรงตลอดวัน = 1.0

### 3. `moon_darkness` — ความมืดของคืน

`1 - illumination_pct/100` — ใช้กับงานกลางคืนที่พึ่งไฟล่อ
[แหล่งข้อมูลตกหมึกตรงกัน](https://www.egitex.com.au/blogs/news/the-ultimate-guide-to-squid-jigging-color-technique-and-top-spots)
ว่าคืนเดือนมืดหมึกเข้าไฟดีกว่า เพราะแสงไฟตัดกับความมืดได้ชัด

### 4. `solunar` — อยู่ในช่วง major/minor ไหม

1.0 = อยู่ในช่วง major · 0.6 = อยู่ในช่วง minor · 0.25 = ไม่อยู่ในช่วงไหนเลย
(ไม่ให้ 0 เพราะไม่มีหลักฐานว่านอกช่วงแล้วปลาไม่กิน — ให้เป็นแค่แต้มต่อเล็กน้อย)

### 5. `light_phase` — ช่วงแสง

คำนวณจาก sunrise/sunset จริงของวันนั้น
1.0 = ช่วงเช้ามืด/พลบค่ำ (±1 ชม. รอบพระอาทิตย์ขึ้น-ตก) · 0.7 = กลางคืน · 0.5 = กลางวัน
[ปลานักล่าออกหากินช่วงแสงน้อยมากที่สุด](https://www.ryanmoodyfishing.com/fishing-tips-for-giant-trevally-gt/)

### 6. `wind_calm` — ลมสงบแค่ไหน

1.0 ที่ลม 0 และลดลงเป็นเส้นตรงจนเป็น 0.0 ที่ 40 กม./ชม.
งานที่ต้องคุมเรือหรือคุมสายจะให้น้ำหนักตัวนี้เยอะ

### 7. `wave_calm` — คลื่นสงบแค่ไหน

1.0 ที่คลื่น 0 ม. ลดลงเป็นเส้นตรงจนเป็น 0.0 ที่ 2.5 ม.
ถ้าจุดนั้นไม่มีข้อมูลคลื่น จะใช้ค่ากลาง 0.5 และระบุไว้ใน `note` ของ breakdown ตรง ๆ

### 8. `dry` — โอกาสไม่มีฝน

`1 - precipitation_probability_pct/100`

## คะแนนรวม (`overall`)

**= ค่าเฉลี่ยของ 3 งานที่ได้คะแนนสูงสุดในวันนั้น**

เหตุผลที่ไม่ใช้ค่าเฉลี่ยของทุกงาน: วันที่ลมแรงจัดจะมีงานชายฝั่งได้คะแนนดีอยู่งานเดียว
ค่าเฉลี่ยทั้งหมดจะฉุดจนดูเหมือนวันแย่ ทั้งที่จริงยังมีอะไรให้ทำ

เหตุผลที่ไม่ใช้คะแนนสูงสุดงานเดียว: จะได้ 85-95 แทบทุกวันจนตัวเลขไม่มีความหมาย

การเฉลี่ย 3 อันดับแรกอยู่ตรงกลาง — **วันที่ดีคือวันที่มีงานให้เลือกทำหลายอย่าง**

### ป้ายกำกับ

| คะแนน | ป้าย |
|---|---|
| 80-100 | ดีมาก |
| 65-79 | ดี |
| 50-64 | พอใช้ |
| 0-49 | ไม่เด่น |

## เวอร์ชันของสูตร

`meta.formula_version` เปลี่ยนทุกครั้งที่น้ำหนักหรือสูตรเปลี่ยน
`trip_plans.score_inputs` เก็บ input ที่ใช้คิดคะแนนของทริปนั้นไว้ในฐานข้อมูล
ทำให้ย้อนตรวจได้ว่าคะแนนเก่ามาจากสูตรเวอร์ชันไหนและ input อะไร

**ปัจจุบัน: `1.0`**

## สิ่งที่รู้ว่ายังไม่ดีพอ

1. **น้ำหนักมาจากการอ่านเอกสารและประสบการณ์ ไม่ได้มาจากข้อมูลจริงของน่านน้ำเรา**
   ยังไม่มี `catch_logs` มากพอจะปรับน้ำหนักด้วยข้อมูล
2. **`water_movement` เป็นแบบ "ยิ่งแรงยิ่งดี" กับทุกงาน** ซึ่งไม่จริงสำหรับ `float` และ `lightgame`
   ต้องเปลี่ยนเป็นเส้นโค้งที่มีจุดเหมาะสมตรงกลาง (optimum curve) ในเวอร์ชันหน้า
3. **ไม่แยกตามสายพันธุ์ปลา** ซึ่งเป็นสิ่งที่ Fishbrain ทำได้เพราะมีข้อมูล 2.5 ล้านรายการ
4. **ไม่มีอุณหภูมิน้ำ** ทั้งที่งานวิจัยข้างต้นพบว่าอุณหภูมิทำนายได้ดีกว่า solunar
   Open-Meteo Marine มี `sea_surface_temperature` ให้ใช้ — ควรเพิ่มในเวอร์ชันหน้า

### ทางที่ควรไปต่อ

บันทึกสภาพทุกทริปลง `trip_plans.score_inputs` และผลจริงลง `catch_logs`
เมื่อมีข้อมูลของน่านน้ำเราเองมากพอ ค่อยปรับน้ำหนักจากของจริงแล้วขึ้นเป็น `2.0`

⚠️ ตอนนั้นต้องบันทึก **ทริปที่ไม่ได้ปลาด้วย** ไม่งั้นจะมีแต่ข้อมูล "ตอนได้"
แล้วสถิติจะเอียงทั้งชุด — เป็นปัญหาเดียวกับที่ Fishbrain เจอและไม่ได้เปิดเผยวิธีแก้
